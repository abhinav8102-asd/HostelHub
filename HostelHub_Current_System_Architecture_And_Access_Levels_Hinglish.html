2 🏗️ Platform Base, Technology Stack & Server
💻 Technical Architecture & Runtimes Tech Stack
  • Architecture Base: Decoupled Full-Stack Architecture — Centralized Node.js REST API Backend + Independent Frontend Portals. Hybrid Web-to-Native Android APK base.
  • Backend Runtime: Node.js v24+ with Express.js framework.
  • Real-Time Engine: Socket.io Engine (WebSockets for 1-on-1 chat, group chat, and instant push alerts).
  • Database ORM: Sequelize ORM with SQLite database engine (database.sqlite).
  • Frontend Framework: Angular SPA Framework (TypeScript, HTML5, Vanilla CSS3 with custom Glassmorphism Crimson Theme #b31031).
  • Authentication Stack: jsonwebtoken (JWT), bcryptjs (salted hashing), Google OAuth 2.0, Nodemailer OTP engine.
  • Media Upload Handler: Multer middleware for handling images & avatars.
  • Current Server Setup: Node.js Express server running on http://localhost:5000 with integrated Socket.io WebSocket server (server.js).
3 💾 Data Handling & Security Framework
🗄️ Data Handling & Storage Models Database Engine
  • SQLite Database File: backend/database.sqlite managed via Sequelize ORM with auto-migrations.
  • 12 Core Schema Tables: User, Attendance, Complaint, ChatMessage, GroupChat, MessMenu, MessFeedback, MessSkip, Announcement, Notification, PasswordResetOTP, Setting.
  • File Storage Engine: Local disk storage in backend/uploads/ with static file serving (/uploads) and sanitized file naming.
🛡️ Security & Data Protection Architecture Security Core
  • Stateless JWT Bearer Auth: Tokens carried in Authorization: Bearer <token> header with session expiration.
  • Role-Based Access Control (RBAC): Strict auth.js middleware enforcing route protection (authorizeRoles('admin', 'warden')).
  • Bcrypt Salted Hashing: 10-round salted password hashing (Plaintext passwords never stored).
  • SQL Injection & XSS Protection: Parameterized Sequelize ORM queries eliminate SQL Injection vulnerabilities.
  • Upload Security: Strict MIME-type validation (JPEG, PNG, WEBP) & randomized filename generation.
  • Socket Handshake Auth: Authenticated WebSocket handshake prevents unauthorized chat room access.
