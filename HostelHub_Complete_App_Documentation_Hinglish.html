1. 📱 HostelHub Ecosystem Overview (Full App Summary)

HostelHub ek multi-role, end-to-end Smart Hostel Management Platform hai jo student residence lifecycle ko completely digitize karta hai. System 4 dedicated frontends (Portals) aur 1 centralized backend service par chalta hai:

🎓 Student Portal (frontend-user)

Complaint lodging, live roll call attendance, mess feedback, real-time chat, profile management, and push alerts.

👨‍🏫 Warden Portal (frontend-warden)

Block-wise roll call marking, complaint resolution & staff task assignment, mess menu management, announcements broadcast.

🛠️ Staff / Technician Portal (frontend-staff)

Task execution dashboard for Electricians, Plumbers & IT support, task status updates, completion proof upload.

🔑 Super Admin Portal (frontend-admin)

User provisioning, student account approvals, hostel block & room capacity management, global app settings.

3. 💾 Data Storage & Backend Architecture Engine

Backend Node.js + Express framework par structured Sequelize ORM ke sath chalta hai:

🗄️ Database Engine

SQLite Database (database.sqlite) managed via Sequelize ORM with automatic table migrations & indexing.

📁 File Storage (Uploads)

Local uploads/ directory managed by Multer middleware for profile pictures & complaint evidence images.

⚡ Real-Time WebSockets

Socket.io engine (socket.js) handling instant messaging, chat room joining, and real-time notification push.

📜 Database Migration Scripts

Automated scripts (initDb.js, seed.js, migrate_add_google_id.js, migrate_add_chat_fields.js).

🗂️ Core Database Models & Schema Breakdown:

  • User Model (User.js): Stores user profiles, role enum (student, warden, staff, admin), status (active, pending_verification, blocked), Google ID, hashed password, room number, hostel block, roll number, phone, gender, and batch.
  • Attendance Model (Attendance.js): Stores daily roll call entries linked to User ID, date, status (present, absent, outstation), and warden ID.
  • Complaint Model (Complaint.js): Stores complaints with category, title, description, proof image URL, status (pending, in_progress, resolved, rejected), student ID, assigned staff ID, hostel block.
  • ChatMessage & GroupChat Models (ChatMessage.js, GroupChat.js): Stores 1-on-1 and group messages, sender ID, receiver ID, group ID, message text, attachment URL, read receipts.
  • MessMenu, MessFeedback & MessSkip Models: Stores day-wise menu schedules, 1-5 star meal feedback ratings, student comments, and skip requests.
  • Announcement & Notification Models: Stores published circulars, targeted blocks, push notification logs, and read flags.
  • PasswordResetOTP Model: Stores email-linked hashed OTP tokens and expiration timestamps.

4. 🛡️ Security, Privacy & Data Protection Architecture

Security 🔒 Complete System Security Framework

  • JWT Token Authentication: Stateless JSON Web Token authentication with HTTP Bearer Authorization header. Tokens carry user ID, email, and role claims with expiration enforcing re-authentication.
  • Role-Based Access Control (RBAC Middleware): Strict auth.js middleware enforcing route protection (e.g. authorizeRoles('admin', 'warden')). Students cannot access Warden or Admin APIs.
  • Bcrypt Password Hashing: All user passwords are salted & hashed using bcryptjs (10 salt rounds) before storing in DB. Plaintext passwords are never saved.
  • Google OAuth 2.0 Security: Secure Google token validation for single sign-on without password exposure.
  • SQL Injection & XSS Protection: Sequelize ORM provides fully parameterized SQL queries, eliminating SQL Injection vulnerabilities. Inputs are sanitized against XSS attacks.
  • Multer Storage Security: File upload validation enforcing allowed MIME types (JPEG, PNG, WEBP), file size caps, and random filename generation to prevent arbitrary file execution scripts.
  • Environment Isolation: Sensitive keys (JWT Secret, Database path, Server Port) isolated in server .env file.
  • Socket.io Room Authorization: Real-time chat socket connections require handshake token authentication, isolating group chat channels to authorized members only.
